# GEO 自动采集浏览器插件需求

## 一、产品目标

开发一个浏览器插件，用于自动检测关键词/提示词在主流 AI 搜索与问答平台中的内容表现，并导出本次检测结果。

用户只需要输入关键词列表，插件自动完成搜索、采集、截图和文件导出。

## 二、适配平台

插件需要适配以下 AI 平台：

- ChatGPT
- Claude
- Gemini
- Perplexity

国内平台

## 三、核心功能

### 1. 关键词输入

用户点击浏览器插件图标后，在插件弹窗中输入关键词/提示词列表。

要求：

- 支持批量输入
- 支持一行一个关键词
- 支持复制粘贴多条关键词
- 支持选择检测平台，默认全选

### 2. 自动搜索

用户点击“开始检测”后，插件自动按关键词列表执行搜索/提问。

要求：

- 自动打开或切换到对应 AI 平台
- 自动输入关键词/提示词
- 自动提交搜索/提问
- 自动等待 AI 内容生成完成
- 支持批量任务顺序执行
- 支持任务进度展示
- 支持失败跳过或重试
- 支持手动停止任务

### 3. 内容采集

每个关键词在每个平台搜索完成后，插件需要采集以下内容：

- 关键词/提示词
- AI 平台名称
- 采集时间
- AI 返回的正文内容
- 引用链接列表
- 当前结果页面截图
- 整个对话区域的 DOM 节点内容

说明：

- 不需要单独下载或保存图片资源
- 图片内容通过页面截图保留即可
- DOM 节点内容用于后续结构化分析和结果追溯
- 正文内容应尽量提取对话结果主体，避免采集无关导航、侧边栏、广告等内容

### 4. 文件导出

检测完成后，插件自动导出本次检测结果。

导出文件包括：

- HTML 文件：包含关键词、平台、正文内容、引用链接、对话 DOM 内容等
- 截图文件：保存每个关键词在每个平台上的结果页面截图

## 四、HTML 结果内容

导出的 HTML 文件至少包含：

- 本次检测时间
- 检测平台
- 关键词列表
- 每条关键词的 AI 回答正文
- 每条关键词的引用链接
- 每条关键词对应的对话 DOM 节点内容
- 对应截图文件路径或截图索引

## 五、用户使用流程

1. 用户点击浏览器插件图标
2. 在输入框中输入要检测的关键词/提示词列表
3. 选择要检测的 AI 平台，默认全选
4. 点击“开始检测”
5. 插件自动访问对应平台并逐条执行搜索
6. 插件自动采集正文、引用链接、对话 DOM 和截图
7. 检测完成后，用户获得本次检测的 HTML 文件和截图文件

## 六、基础要求

- 支持批量关键词检测
- 支持 ChatGPT、Claude、Gemini、Perplexity
- 支持手动停止
- 导出的 HTML 需要尽量和线上内容一致
- 截图需要能对应到具体关键词和平台
- 对话 DOM 内容需要完整保存，方便后续做结构化解析

## 七、需要开发体验证和解决的点

以下内容需要由有浏览器插件开发经验的开发人员进一步验证和落地：

- 如何上线一个可用的浏览器插件 Demo
- 不同平台页面 DOM 结构不同，需要分别适配正文、引用链接和对话节点的提取规则
- 如何判断 AI 回答已经生成完成
- 如何截取当前页面或指定对话区域截图
- 如何将 HTML 文件和截图文件打包下载
- 如何处理用户未登录、页面加载失败、平台改版、网络异常等情况
- 需要支持本地存储历史任务和采集记录
- 是否需要支持 Chrome Web Store 上架，或只提供本地安装 Demo

## 八、风险提示

该插件涉及自动访问和采集第三方 AI 平台页面，需要注意以下风险：

- 尽量模拟人工操作，避免明显的机器行为
- 不要请求过快，关键词之间需要设置合理等待时间
- 不要同时打开过多页面或并发执行过多任务
- 避免短时间内大量重复提问，防止触发平台风控或反爬机制
- 不同 AI 平台可能限制自动化访问，插件需要做好失败提示
- 平台页面结构可能随时变化，采集规则需要可维护
- 用户账号可能受到平台风控影响，需要在产品中做风险提示
- 采集结果仅用于用户自己的 GEO 检测和内容分析，不应绕过平台权限或访问限制
