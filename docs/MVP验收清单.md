# MVP 验收清单

当前验证状态（2026-11-12，扩展 0.6.8）：23 项模拟与协议测试、2 项实际 Chromium 测试通过；manifest、JavaScript 语法和扩展入口检查通过。真实 Perplexity 三问验收尚未通过，正文与引用未完成采集核对。

## 自动化范围

`npm run check` 验证 manifest、入口文件和 JavaScript 语法。`npm test` 使用临时数据目录与回环端口运行以下检查：

- 离线 help/docs，文档请求示例通过同一参数校验。
- HTTP、CLI 与扩展直接连接，不生成凭据文件；跨实例重连与扩展离线错误。
- 持久化幂等、并发拒绝、服务重启后的原任务查询。
- 正文分页、引用、轻量摘要、事件游标与去重。
- 历史诊断分层读取、PNG 独立二进制交付。
- 真实 bridge、后台和 runner 代码在模拟网页上的消息闭环。
- 受控编辑器异步提交后再校验输入，校验失败时不发送。
- SPA 加载状态保持原 runner；DOM 已可用时不等待全部资源完成。
- Session 页面的问题与最终回答按轮次关联，问题复制按钮不作为回答完成信号。
- 多次采集、完成信号缺失、多个回答候选、部分结果。
- 停止确认、后台重启恢复、关闭标签页后的中断。
- 选择器实测、显式保存、配置版本冲突。

DOM、Chrome API、截图像素和 IndexedDB 环境为测试替身，不是当前网站或 Chrome 真实运行证据。

## 实际 Chromium 自动化范围

`npm run test:browser` 使用 Playwright 自带 Chromium、独立临时用户目录及本机 HTTPS 测试页。浏览器内运行实际扩展，使用真实 Chrome API、IndexedDB、Service Worker 和截图能力。

- [x] 加载 manifest 和扩展后台，界面动态读取版本。
- [x] 界面直接连接实际 bridge，无凭据输入框。
- [x] 从界面发起新对话采集，保存本轮正文和引用。
- [x] 同页 collect 不重复提交问题。
- [x] debugger 截图生成真实 PNG，并通过文件接口取回。
- [x] HTML 报告能够下载。
- [x] 实际终止 Service Worker 后接回原 runner，不重复提交。
- [x] 页面刷新后原任务进入 interrupted，不自动重提。

以上测试页面由本机服务提供，不使用真实 Perplexity 页面和用户账号。测试不证明登录、验证码、实际平台 DOM 或不同页面模式已经适配。

## 用户 Chrome 验收

以下项目需在用户实际使用环境执行，当前未完成。实际操作用户电脑前取得明确同意。

- [ ] 加载项目根目录，扩展无 manifest 或后台错误。
- [ ] 本机服务连接成功，CLI status 显示 connected 和 ready。
- [ ] 关闭侧栏后任务继续，重新打开显示同一状态。
- [ ] 后台停止后恢复同一任务，不重复提问。
- [ ] bridge 重启后重连，未确认事件重放但结果不重复。
- [ ] 浏览器关闭再启动后旧任务如实中断，不自动重提。
- [ ] 更换浏览器实例后直接连接，丢失执行上下文的任务如实中断。

- [ ] 新对话：输入与发送成功，返回本次回答。
- [ ] 已有对话：仅采集、不发送问题。
- [ ] 多轮对话和重复问题：正确关联当前轮次。

- [ ] 网络停顿、长思考：不把静止正文误判为完成。
- [ ] 可见引用与页面核对，结果明确说明未展开来源弹层。
- [ ] 前台与后台标签页分别验证并记录差异。
- [ ] 登录失效、验证页面、额度限制能够报告可理解的失败。
- [ ] 多标签页必须选择目标，不操作错误页面。

## 故障、修复与交付

- [ ] 在发送前、发送后、正文保存前分别中断，不自动重复提交。
- [ ] 关闭或刷新标签页，原任务进入正确终态。
- [ ] stop 后原 runner 真正结束；未确认时不显示停止成功。
- [ ] 错误、过宽、歧义选择器保留失败现场。
- [ ] 实测选择器通过后显式保存，后续任务使用新配置。
- [ ] 旧 revision 保存被拒绝，历史结果不会被修复操作改写。
- [ ] 真实节点截图下载为可打开 PNG；失败不影响已有正文。
- [ ] DevTools 打开、页面布局变化和后台截图分别记录结果。
- [ ] 正文、引用、原始 HTML、QA DOM 可按需读回。
- [ ] JSON 与 HTML 报告核对正确，报告不执行采集内容中的脚本。
- [ ] 默认 help、task、result、events 无正文全文、整页 DOM 或 Base64。

验收记录应包含日期、Chrome 与扩展版本、平台模式、任务 ID、操作条件、结果及限制。未验证的能力保持“待验收”，不以接口存在或模拟测试通过代替真实采集成功。
