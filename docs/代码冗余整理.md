## 一、Adapter 层重复（最严重）

7 个平台 adapter（`perplexity / chatgpt / gemini / claude / doubao / yuanbao / kimi`）里，大量函数是同一套骨架复制粘贴，仅选择器不同。

### 1.1 完全可复制粘贴的骨架函数

| 函数 | 存在文件 | 说明 | 建议 |
|------|---------|------|------|
| `runXxxTask(query, config)` | 全部 7 个 | 统一流程：makeTrace → findInput → humanType → 发送 → 等 3s → login 检查 → collect(true) | 抽到 `base.js` 模板方法 |
| `collectXxxPage(config)` | 全部 7 个 | 统一流程：makeTrace → login 检查 → findLastQA/answerRoot → 长度检查 → collect(false) | 抽到 `base.js` 模板方法 |
| `collect(config, ensureComplete, tr)` | 全部 7 个 | 等待生成+采集的分支逻辑几乎一致 | 抽到 `base.js`，平台只传参数 |
| `findInput()` | 全部 7 个 | 20 次尝试 / 500ms 的循环完全一致，只有 `selectors` 数组不同 | 抽到 `common.js`：`findInputWithRetry(selectors)` |
| `loginRequired()` | 全部 7 个 | 都是 `location.href` 正则，只有 regex 不同 | 抽到 base：传 `loginUrlPattern` |
| `inferKeyword()` | 全部 7 个 | 都是「用户文本 → 清洗 title → '当前页面'」 fallback | 抽到 base：传选择器和 titlePattern |
| `answerRoot(qa)` | 全部 7 个 | 都是「assistant 容器 → markdown/prose 子节点 → 最长 div 兜底」 | 抽到 base，平台只覆盖选择器 |
| `findSendButton()` | 大部分 | 都是找一个发送按钮 | 抽到 base，平台只覆盖选择器 |

### 1.2 可在 common.js / base.js 复用的平台工具

| 函数 | 当前位置 | 建议 |
|------|---------|------|
| `expandSources()` | `perplexity.js`, `gemini.js` | 抽到 `common.js`：`expandSources(labels, root)` |
| `buildShotSelector(qa)` | `doubao.js`, `kimi.js` | 抽到 `common.js`：`GEO.buildShotWrapper(...)` |
| `isXxxGenerating()` | `perplexity/doubao/yuanbao/kimi` | 部分平台用通用 `G.isGenerating()`，部分自定义；统一为「adapter 可选覆盖 `isGenerating` hook」 |

### 1.3 真正必须留在各 adapter 的平台特异性代码

- **选择器数组**（输入框、QA 列表、停止按钮）
- **ChatGPT** `findLastQA`：用 `data-turn-id-container` + `data-message-author-role`
- **Gemini** `answerRoot`：用 `model-response` / `message-content`
- **元宝** `answerRoot` 的 THINK / CoT 排除逻辑
- **豆包** `typeReact`：React 受控 textarea 需要 native setter
- **豆包/元宝/Kimi** 自定义 `isGenerating`（基于 SVG / 类名状态）
- **Kimi** `geoGetQANodeSelector` 暴露给 SW 的截图定位

### 1.4 Adapter 里「错的」实现 / 不一致导致的问题

| 问题 | 位置 | 影响 | 优先级 |
|------|------|------|--------|
| **Claude 没有 `findLastQA`** | `claude.js` | 没有 `qaHtml`、`qaSelector`，引用扫描扫全页（含 sidebar） | 高 |
| **Claude `answerRoot` 忽略 `qa` 参数** | `claude.js` | 与 api 签名不一致 | 中 |
| **元宝 title 正则太激进** | `yuanbao.js` | `replace(/\s*[|\-–]\s*.*$/i,'')` 把 dash 后所有内容全删掉 | 高 |
| **Perplexity `findSendButton` 没检查 `disabled`** | `perplexity.js` | 可能点到禁用按钮 | 中 |
| **Kimi `findSendButton` 没检查可见性** | `kimi.js` | 可能选到隐藏按钮 | 中 |
| **collect 分支写法不一致** | 各 adapter | 有的 `ensureComplete \|\| isGenerating()`，有的 `if/else` | 低 |
| **返回字段不一致** | 各 adapter | `domHtml` 在 chatgpt/gemini/claude 有，其他没有；`qaSelector` 在 claude 缺失 | 中 |
| **answerRoot 签名不一致** | gemini/claude | 忽略传入的 `qa` 参数 | 低 |

### 1.5 推荐重构方式

创建 `src/content/adapters/base.js`，用**模板方法 + hook**模式：

```
BaseAdapter
├── runTask(query, config)        // 固定骨架
├── collectPage(config)           // 固定骨架
├── collect(...)                  // 固定等待/采集逻辑
├── findInputWithRetry(selectors) // 通用
├── buildShotWrapper(...)         // 通用
├── expandSources(...)            // 通用
└── hooks（子类覆盖）
    ├── inputSelectors
    ├── sendButtonSelector / findSendButton
    ├── isGenerating
    ├── findLastQA
    ├── answerRoot
    ├── loginUrlPattern
    ├── inferKeyword
    └── minChars / maxWait
```

预计可删掉 adapter 里 **60–70%** 的重复代码。

## 二、截图库重复

### 2.1 当前截图实现

| 文件 | 方案 | 当前角色 |
|------|------|---------|
| `src/lib/screenshot-node.js` | `html-to-image` 节点渲染 | 首选 fallback |
| `src/lib/screenshot-cdp.js` | `chrome.debugger` + `Page.captureScreenshot` | 第二 fallback |
| `src/lib/screenshot.js` | `tabs.captureVisibleTab` + 滚动裁剪/拼接 | 第三 / 整页 fallback |
| `src/lib/html-to-image.min.js` | 库文件 | 在用 |
| `src/lib/html2canvas.min.js` | 库文件 | **完全未引用，死代码** |

### 2.2 重复的工具函数

- `dataUrl → Blob/Bitmap` 转换在三个截图文件里各写了一遍：
  - `screenshot.js`: `dataUrlToBitmap()`
  - `screenshot-node.js`: `dataUrlToBlob()`
  - `screenshot-cdp.js`: `base64ToBlob()`

### 2.3 死代码 / 多余代码

| 代码 | 说明 |
|------|------|
| `src/lib/html2canvas.min.js` | 没有任何 import / script 引用 |
| `kimi.js` 里的 `geoGetQANodeSelector` | SW 和其它文件都没调用 |
| `screenshot-node.js` 重复注入 `common.js` | SW 已经注入过了，虽然 harmless 但多余 |

### 2.4 各方案的好坏

| 方案 | 优点 | 缺点 |
|------|------|------|
| `html-to-image` | 节点独立渲染，不受父容器影响 | 跨域图片/字体可能失败；shadow DOM 支持差；需要节点在视口 |
| CDP | 还原 100%，可靠 | 需要 `debugger` 权限；页面顶部出现官方黄条；会临时改样式 |
| `captureVisibleTab` 裁剪 | 无黄条 | 受视口限制；固定/粘性 header 会重复；不能展开 `overflow:hidden` |
| 整页滚动拼接 | 兜底 | `MAX_SEGMENTS=20` 会静默截断；滚动误差可能错位 |

### 2.5 推荐整理

1. **删除 `html2canvas.min.js`**（死代码）。
2. **新建 `src/lib/media-util.js`**：统一 `dataUrlToBlob`、`base64ToBlob`、`dataUrlToBitmap`。
3. **把 `buildShotSelector` 抽到 `common.js`**，供豆包/Kimi 共用。
4. **删除 `kimi.js` 里的 `geoGetQANodeSelector`**（未使用）。
5. **`screenshot-node.js` 不再重复注入 `common.js`**，只注入 `html-to-image.min.js`。
6. **可选**：把三个截图后端合并成一个 façade：`captureScreenshot(tabId, windowId, selector)`，内部走 4 级 fallback，SW 只调一个函数。
